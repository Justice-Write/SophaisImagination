# Claude instructions

**Before doing anything in this repository, read `STATUS-HANDOFF.md` in the repository root and follow its handoff protocol.**

In short:

1. Read `STATUS-HANDOFF.md` fully before you touch the repo.
2. **Before** you start any work, add an entry under its **ACTIVE WORK** section: the date, your model or agent name, what you're about to do, and which files. Save it before your first edit.
3. **After** you finish, or whenever you stop, remove that entry. Update the current state, next actions and work log, and add a `CHANGELOG.md` entry.
4. If you find someone else's ACTIVE WORK entry, another agent may be mid-task. Don't edit the same files or switch the shared checkout's branch; follow the handoff's step 4.
5. This repository is public and general-audience. Never commit private paths, emails, credentials, prompts, lyrics, unpublished lore, or private brand references.
6. Never push, deploy, post, generate, purchase, or change accounts without the owner's explicit approval.

## Handoff (mandatory)
Read `STATUS-HANDOFF.md` in this folder **before doing anything**, and follow its operating protocol: log planned work under ACTIVE WORK *before* starting, and update it (state, next actions, work log) *after* finishing or stopping.
